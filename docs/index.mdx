---
title: "Introduction"
description: "StoryGet scrapes stories from the web into a local library you can organize, search, and export."
---

StoryGet is a Node.js app (Express, Puppeteer, Cheerio, SQLite) that pulls story text out of web pages and stores it in a local `stories.db` database. It comes with a web UI and a JSON API.
