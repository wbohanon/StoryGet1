## GET /export

| Query | Default | Description |
| --- | --- | --- |
| `format` | `json` | `json`, `csv`, `txt`, `html`, `epub`, `markdown`, or `md` |
| `filename` | `stories.<format>` | Output file name |

Returns `{ "filename", "count", "format" }`.

## GET /download/:filename

Downloads an exported file. `404` if it doesn't exist.
